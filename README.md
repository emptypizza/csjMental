# csjMental

재미로 오늘 나를 읽어 보는 짧은 문진입니다. 의학적 진단이나 처방이 아닙니다.

진료실 의자에 앉은 사람은 플레이어입니다. 간호사 한석지가 안내하고, 고른 말이 곧 오늘의 기록입니다.

## 플레이

화면은 기존 진료 게임과 같습니다. 왼쪽은 한석지, 오른쪽은 기록부입니다. 대사를 클릭하면 다음으로 넘어가고, 타이핑 중이면 대사가 끝까지 납니다.

1. 앉아 보기를 누른 뒤, 아침·사람들·갑자기·오늘 밤 순서로 말을 듣습니다.
2. ◀ ▶ 로 말을 넘기고, 가까운 문장에서 단서 확보를 누릅니다.
3. 고른 말을 오른쪽 오늘의 백과에 올리거나 눌러 읽습니다. 모두 읽어야 기록부가 열립니다.
4. 무게, 자리, 오늘 한 가지를 그 말의 표와 같게 놓습니다. 칸을 누르거나, 단어를 끌어다 놓습니다.
5. 맞으면 스탬프와 가벼운 프로필이 나옵니다. 다르면 기록부가 흔들리고 한석지가 다시 놓게 합니다.

많이 힘든 말을 고르면 프로필 없이 상담 전화만 안내합니다.

## 실행

```bash
npx serve
```

브라우저에서 안내된 주소로 들어갑니다. 빌드 없이 정적 파일로 동작합니다.
